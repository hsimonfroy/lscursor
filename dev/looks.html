Field look — tone curve and colour map

Same field, same seed, same clip quantiles unless stated. The tone curve is applied to the clipped value t ∈ [0,1] before the colour map: t → asinh(knee·t)/asinh(knee) → t^gamma → lift + (1−lift)·t. "median" below each thumbnail is where a typical pixel lands on the colour ramp — the app ships with asinh knee 2 and q = 1e-4, which puts it near 0.10; the old linear ramp sat at 0.07.
